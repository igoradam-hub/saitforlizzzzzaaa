ШАГ 2: ЗАГРУЗИ В WORDPRESS
═══════════════════════════════════════════════════════════════════

1. Войди в админку WordPress
   Адрес: твойсайт.ru/wp-admin

2. В левом меню нажми:
   "Внешний вид" → "Темы"

3. Нажми кнопку "Добавить новую" (вверху)

4. Нажми кнопку "Загрузить тему" (вверху)

5. Нажми "Выберите файл"

6. Выбери файл: msu-urban-law-cup.zip

7. Нажми "Установить"

8. Подожди пока загрузится (10-30 секунд)


═══════════════════════════════════════════════════════════════════
ШАГ 3: АКТИВИРУЙ ТЕМУ
═══════════════════════════════════════════════════════════════════

1. После загрузки нажми "Активировать"

2. ГОТОВО! Сайт работает!

3. Открой свой сайт и проверь: твойсайт.ru

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
═══════════════════════════════════════════════════════════════════

Проблема: "Не удалось установить тему"
Решение: Проверь что файл .zip не повреждён

Проблема: "Тема не найдена"
Решение: Убедись что внутри архива есть папка msu-urban-law-cup

Проблема: "Картинки не отображаются"
Решение: Проверь что папка images скопировалась полностью

Проблема: "Ошибка PHP"
Решение: Нужен PHP версии 7.4 или выше

КАК ИЗМЕНИТЬ ТЕКСТ НА САЙТЕ
═══════════════════════════════════════════════════════════════════

1. Зайди в: "Внешний вид" → "Редактор тем"
2. Справа выбери: index.php
3. Найди нужный текст и измени
4. Нажми "Обновить файл"

ИЛИ через FTP:
1. Подключись к серверу через FileZilla
2. Путь: /wp-content/themes/msu-urban-law-cup/
3. Скачай index.php
4. Отредактируй в Notepad++
5. Загрузи обратно
